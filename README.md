# Repas chantier

Application locale, sans compte ni installation.

## Lancer l’application

Double-cliquez sur `index.html` : elle s’ouvrira dans votre navigateur.

Les repas et les photos de tickets sont conservés uniquement dans les données locales de ce navigateur. Pour les retrouver, ouvrez toujours le fichier avec le même navigateur et sur le même ordinateur.

## Sauvegarde complète

Cliquez régulièrement sur **Créer une sauvegarde** et conservez le fichier `.json` dans un endroit sûr (clé USB, dossier Documents ou cloud). Il contient tous les repas et les photos de tickets. En cas de changement d’ordinateur ou si les données du navigateur sont effacées, utilisez **Restaurer une sauvegarde** pour retrouver l’ensemble des données.

## Export mensuel

Choisissez le mois puis cliquez sur **Exporter le mois pour LibreOffice**. Le fichier CSV téléchargé s’ouvre avec LibreOffice Calc et contient la date, le chantier, le prix, la présence d’un ticket et le total.
